# Graphical Shape Editor (Java Swing)

A Paint-like vector graphics editor built with Java Swing and AWT.

> **Note:** Archived 2025 OOP coursework.

## Features
- Draw points, lines, circles, ovals, rectangles, and polylines
- Custom color selection (`JColorChooser`)
- Select, shift, delete, and clear shapes
- Save and load drawings using `;`-delimited text files

## Running
```bash
javac *.java
java Editor
